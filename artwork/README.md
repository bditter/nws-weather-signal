# Artwork

The NWS Weather Signal mark is original project artwork generated for this
repository on June 14, 2026, using OpenAI's built-in image generation tool.
It is released with the project under the MIT License.

The mark is intentionally separate from NOAA, National Weather Service, and
Home Assistant seals and logos.

## Generation prompt

```text
Create an original, bold, text-free icon for a project named NWS Weather
Signal. Combine a simplified weather warning signal beacon with a stylized
storm cloud and one crisp lightning bolt. The beacon should suggest radiating
alert waves without resembling any existing government seal or app logo.

Use a clean, flat, vector-like geometric style that remains legible at 32px.
Use deep navy, vivid electric cyan, a warm amber warning accent, and white
highlights. Center the emblem in a square with generous padding. Do not include
text, letters, numbers, flags, maps, NOAA/NWS seals, the Home Assistant logo,
or watermarks.
```
